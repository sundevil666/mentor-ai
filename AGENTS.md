# Agent Notes

- After completing code changes in this project, always create a git commit and push it to the remote branch.
- In the final response, explicitly state that the commit and push were completed.
- Before creating or changing any personalized English lesson, first read `.ai/private/README_ENGLISH_LESSON_WORKFLOW.md` when that local private file exists, then follow its refresh and lesson-planning sequence. Never commit files from `.ai/private/`.

- Before adding or editing public audio books, stories, chapters, or multipart recordings, read and follow [the audio catalog workflow](.ai/README_AUDIO_CATALOG_WORKFLOW.md). Every multi-track work must have explicit collection metadata and use the existing persistent expandable card.
